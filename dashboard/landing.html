Heurísticas de URL

Análisis Estructural

Inspecciona la composición de subdominios sospechosos, longitud extrema de URL, ausencia de HTTPS y patrones comunes utilizados por atacantes.

  • Detección estática inmediata
  • Exclusión de dominios de confianza
  • Baja carga computacional
⚖️

Similitud Léxica

Detección de Typosquatting

Compara en caliente el dominio con marcas reales mediante el algoritmo de distancia de Levenshtein para identificar variaciones tipográficas maliciosas.

  • Protección contra suplantación
  • Base de datos de marcas integrada
  • Evita redirecciones confusas
🛡️

Reputación Global

Integración con VirusTotal v3

Consulta a más de 90 motores de reputación globales mediante APIs cifradas asíncronas, acelerado por una lista negra local de phishing verificado.

  • Base de amenazas global activa
  • Cacheo inteligente de consultas
  • API Key cifrada en contenedores
🤖

Machine Learning (ONNX)

Inferencia con Random Forest

Inferencia local instantánea mediante un modelo Random Forest entrenado con el dataset público PhishStorm (más de 95,000 registros) y empaquetado en formato ONNX.

  • 93.2% de precisión en inferencia
  • Verificación automática de firma de modelo
  • FastAPI asíncrono en Python
👁️

Análisis Visual Perceptual (pHash Local)

Verificación Local de Logos

Novedoso sistema que reduce la latencia de análisis visual a cero: la extensión realiza una captura de pantalla local de la pestaña activa (`captureVisibleTab`), calcula su hash perceptual de imagen mediante `OffscreenCanvas` y `createImageBitmap` directamente en el Service Worker de Chrome, y el servidor valida si imita la firma de marcas reales con un umbral de Hamming de ≤ 8.

  • Sin latencias de navegadores headless en el backend
  • Privacidad garantizada (análisis en memoria local)
  • Detección directa de logotipos protegidos

CONGRESO NACIONAL DE CHILE

LEY N° 21.663

Ley Marco de Ciberseguridad: Exige a las empresas y operadores de infraestructura crítica la implementación de medidas de seguridad proactivas contra incidentes cibernéticos.

LEY N° 21.113

Delitos Informáticos: Tipifica y sanciona penalmente conductas como el acceso ilícito, sabotaje informático y el fraude por suplantación (phishing).
